Консольная программа на JAVA для работы с матрицами комплексных чисел. Позволяет складывать, вычитать, умножать, делить, искать обратную, транспонированную, считать определитель.<br>
Матрица C является временной хранящей последнее существенное действие.<br>
Любой результат последующих операций(кроме вывода и подсчета определителя и задания A/B) изменит матрицу C.<br>
Комплексное число вида 2+2i записывать в виде 2 2.<br>
Буквы вводить на английском(без пробелов).
